Updated: stage 7 part B (UX: toast says what was saved, «Последняя запись», countdown, «Дела» done, plain Settings); part A (debts, several amounts, deposits from a wallet, hours, currency, duplicate guard).

## App
- `index.html`, `src/main.ts`, `src/style.css`: the app shell (tabs, service worker registration).
- `src/config.ts`: configurable defaults: wallets and their spoken aliases (stems), MSK offset, default hour (12:00 MSK).
- `src/parser/`: the rules parser for dictated Russian. Entry point `parse(text, now, wallets)` in `index.ts`.
  - `normalize.ts`: number words to digits («три тысячи двести» → 3200, «шесть с половиной» → 6,5, «двадцать пятого» → 25-го), «3 000» → 3000, «полтора часа» → 90 минут. `fold()` = lower-case + ё→е, same length.
  - `time.ts`: chrono-node `ru` with reference `{ instant: now, timezone: 180 }`, `forwardDate`; no hour → 12:00 MSK; own regex for «17-го (числа)» and «в 10:00»; `nextDayOfMonth()`. UTC getters on (instant + 3 h) only, never the device zone.
  - `money.ts`: amount → integer kopecks, rate «под 6,5%», term «на 6 месяцев / год / полгода».
  - `wallets.ts`: wallet mentions by alias stem, with the preposition before them (transfer direction).
  - `text.ts`: Cyrillic-safe word regex helper, title cutting.
  - `rules/<kind>.ts`: one file per kind. Priority order is the `RULES` array in `index.ts`: idea prefix → reminder («напомни») → transfer → held → debt/repay (`debt.ts`) → deposit → subscription → income → expense → reminder (exact hour, no marker) → expense (amount + currency/wallet) → reminder (утром/днём/вечером, «к девяти») → expense short («кофе 300»: 1–3 words + amount at the end, no wish words) → expense lead («5000 ремонт»: amount first, ≥ 1000 ₽, 1–3 words, no day/time) → idea fallback (low confidence). Stage 7: «вчера/позавчера» on a money kind → `fields.happened_utc` (the rules run again on the text without the day words); «долларов/евро» → `fields.currency`; walletless phrases («Маша должна мне 1500») carry `walletless`.
  - Stage 7 helpers: `when.ts` (own hour regexes «в 3 часа дня», «полвосьмого», parts of the day; the hour is blanked with a filler before chrono reads the day; a passed hour today → tomorrow; no hour → 12:00 MSK + `no_time`), `names.ts` (`nominative`, `personKey` = grouping key of a person), `many.ts` (`splitExpenses`). `parseMany(text, now, wallets)` in `index.ts` = one ParseResult per amount («кофе 300, булочка 150 и сок 120»), always ≥ 1. `findTimes` drops chrono's lone durations («ремонт часов», «5 минут славы»).
  - `types.ts`: `ParseResult { kind, confidence, fields, tags, raw_text }`, `ParsedFields`.
- `src/db/`: own IndexedDB wrapper. `idb.ts` (promisified requests, versioned `MIGRATIONS`; v1 creates the stores and seeds the default wallets; v2 removes the old «Вклад» wallet if no record uses it and its start balance is 0, and resets a `last_wallet_id` that pointed to it), `db.ts` (`PocketDb`: records, wallets, settings, drafts; every write is an upsert by id; `saveManyFromDraft` writes N records and removes the draft in ONE transaction (`saveFromDraft` = N=1); `softDeleteMany` / `softDelete`), `wallets.ts` (`walletRefs` = wallet list for the parser: VISIBLE wallets only, never the old «Вклад», current names + aliases by stable id; unique-name check), `types.ts`.
- `src/money/`: `format.ts` (own «1 234,50 ₽» formatter and ruble-string -> kopecks parser, no Intl), `totals.ts` (pure math, rules below).
- `src/time/format.ts`: the ONE `formatMsk(utcIso)` (big «23.10 19:00 МСК», small «у тебя 12:00» only when the device zone differs) + MSK helpers for the date-time input. All UI times go through it (`timeEl` in `ui/dom.ts`).
- `src/ui/`: `intake.ts` (`#t=` read once + `replaceState`, listeners for load / `hashchange` / `pageshow`; duplicate guard only for the SAME opening coming back: `isRepeatOpen` = navigation type reload/back_forward on load or `pageshow.persisted` → «Уже записано»; a new load or `hashchange` is a new record), `autosave.ts` (`buildAutoRecords`: `parseMany` with the draft's time -> learned corrections -> default wallet -> `refine` flag per record (parts of a split phrase never); ids `partId(draft.id, i)` = `d`, `d-2`, …; walletless debts get no wallet; returning only-kept money gets no wallet; `defaultWalletId`: named > learned > last > cash > first visible), `toast.ts` (the one bottom toast; a tap or `dismissToast()` removes it WITHOUT `onExpire`, which is how undo / a newer phrase cancel the automatic reminder), `card-model.ts` (sentences «Записал: …», «Уже записано: …», «Понял так: …» for the edit sheet; pure), `card.ts` (the editable card, used only inside the edit sheet), `new-screen.ts` («Новое»: autosave flow, no card), `lists.ts` («Дела», «Мысли»), `money-screen.ts`, `wallet-editor.ts`, `rows.ts`, `settings-screen.ts` (backup, «Умный разбор», version), `app.ts` (shared context, sheet, edit-record, `saveEdited` also writes the corrections memory and the last wallet), `dom.ts`.
- `src/parser/confidence.ts` (`needsModel`: rules are unsure -> `refine: "pending"`), `src/parser/learned.ts` (corrections memory: `learnFromEdit`, `applyLearned`, `sanitizeLearned`, `mergeLearned`; key `${stem}|${rulesKind}`; settings key `learned`). Settings keys `last_wallet_id` and `learned` (`BACKUP_SETTING_KEYS`) travel in the backup.
- `src/model/` (stage 5, the local model; OFF by default): `prompt.ts` (English prompt, JSON schema `{kind}`, `readKind` validates the answer), `engine.ts` (lazy wllama 3.8.1 compat, 1 thread, CPU; shards `public/model/qwen3-0.6b-q4_k_m-0000N-of-00004.gguf` (not in git, only on the laptop and the site) from our own site; `MODEL` in `config.ts`), `cache-fix.ts` (`fixCompressedSizes`: Pages sends the shards gzip-compressed and wllama records the compressed Content-Length as the size, so the cached model never validated and was re-downloaded on every start; sets the real size from `MODEL.shardBytes` when the file has exactly that size), `refine.ts` (`refineRecord`: an idea with `refine: "pending"` becomes expense / income / reminder ONLY if the rules find an amount / a date in the text; the model only names the kind), `refiner.ts` (background queue, one engine, re-reads the record right before the write; records saved during a run are taken in the same run; one failing record does not stop the rest; flags enabled/loading/crashed — `loading` is set only for the memory step after the download (`modelManager.getModelOrDownload` → `loadModel`), left set at start = iOS killed the page → model off; a failed download is not a crash), `setup.ts` (localStorage flags `pb_model_*`, «Уточнил: …» toast with «Отменить», crash toast). `src/ui/model-panel.ts`: «Настройки» → «Умный разбор». `main.ts` runs the queue after every `refresh()`.
- `src/shortcut/payload.ts`: `buildPayload(record, now)` -> `{ title, due, due_local, due_msk, repeat }` (null without a date; subscription = next occurrence via `subscriptionNextDue`; `due` is formatted from UTC getters at +03:00, `due_local` from the device zone) and `buildShortcutUrl(payload)` (`shortcuts://run-shortcut?...`, `encodeURIComponent` only). Format: `docs/shortcut-payload.md`; the Shortcut name is `SHORTCUT_NAME` in `config.ts`.
- `src/backup/` (stage 4, GitHub copy): `serialize.ts` (ALLOWLIST of record/wallet/settings fields; `BACKUP_SETTING_KEYS` in `config.ts`; the token key is refused; `parseBackup` + `sanitize*` for untrusted input), `split.ts` (> `BACKUP.splitBytes` -> `data/records-YYYY-MM.json` by UTC month of `created_utc`, main file keeps wallets/settings/`months`; `fingerprint` = SHA-256 without `exported_utc` to skip unchanged files), `github.ts` (contents API client, injectable `fetch`, GET sha -> PUT base64 UTF-8, 409/422 retry with backoff, error kinds -> Russian messages, logs only status+path), `queue.ts` (single flight + coalescing), `runner.ts` (`createBackupController`: status, `LINKED_KEY` guard against overwriting an existing copy from a new phone), `restore.ts` (`loadRemote`, `mergeBackup`, `applyMerge`), `export.ts` (share sheet or Blob download), `source.ts`, `token.ts`. `PocketDb.setOnChange` fires after every committed records/wallets write (that is the backup trigger); `putMany` = restore in one transaction.
- Token storage: IndexedDB `settings` store, key `github_token` (`token.ts`). Read only by the backup runner, the restore button and `hasToken` (yes/no for the screen). Other settings keys: `backup_last_ok_utc`, `backup_hashes`, `backup_linked`.
- `src/ui/backup-panel.ts` («Резервная копия в интернете»: red `no-backup` line while there is no copy, status, restore with in-page confirm, export; «Ключ доступа»: `token-state` said once, numbered steps, link `TOKEN_PAGE_URL` from `config.ts` (built from `BACKUP`), key field; «Удалить ключ» re-runs the backup so no old error stays), `src/ui/settings-screen.ts`; `model-panel.ts` heading «Умный помощник (необязательно)».
- Stage 7 B: `saved-text.ts` (pure: `recordSentence` / `savedText` / `alreadyText` — «Записал: продукты — 1 250 ₽, Наличные», «Напомню: … — 27.10 09:00 МСК (у тебя …)», «Мысль: …», «Не понял — записал в мысли: …», debts / transfer / deposit / currency sentences, N records compact; `mskDate`), `last-card.ts` («Последняя запись» on top of «Новое», NOT a confirmation card: «Изменить» per record, one «Удалить» for all = undo; the countdown line «Ставлю напоминание через N…» + «Не надо»; the help hint is hidden while it runs), `auto-open.ts` (the one automatic-open timer: `scheduleAutoOpen` / `cancelAutoOpen` / `autoOpenLeft`; cancelled by undo, «Изменить», «Удалить», a manual tap, «Не надо», a new phrase), `shortcut-help.ts` (THE one place with the Shortcut steps from SETUP §4, a sheet behind «как сделать»; stage 8 replaces it). `lists.ts` «Дела»: upcoming (nearest first) → «Прошедшие» → collapsed «Сделано (N)»; a checkbox `data-action="done"` sets `fields.done_utc` (reminders only). `rows.ts`: subscription sub-line «платёж DD.MM»; `inPerson` rows say what happened. `money-screen.ts`: wallets → «Последние операции» (`RECENT_OPERATIONS` + «Показать ещё») → debts per person → deposits → subscriptions. `card.ts`: due field `datetime-local`, typed «27.10.2026 19:00» also read (`fromMskInput`), an unreadable value never wipes the saved time.

## Money rules (src/money/totals.ts)
- Wallet balance = start balance + income - expense - deposit - transfers out + transfers in; debt to_me (I lent) −, debt from_me (I borrowed) +, repay by_me −, repay to_me + (only when the record has a wallet). Deleted records are excluded; hidden wallets are still counted (and shown under «Скрытые кошельки»). «Всего» on the wallets block = sum over ALL wallets, hidden too.
- held («чужие деньги»), subscription, reminder and idea records NEVER change a wallet balance. Records with `fields.currency` (USD/EUR) are listed but never enter ANY ruble sum (balances, deposits, subscriptions, debts). A record with no wallet (or an unknown wallet id) counts in no wallet.
- «Долги и чужие деньги» (`debts`): records grouped by `personKey(who)`; net = +debt to_me − debt from_me − held + repay by_me − repay to_me; `owedToMe` = sum of positive nets, `iOwe` = sum of negative ones. `held.total` = sum of held amounts; «Вклады» = sum of deposit amounts; «Подписки» = sum of subscription amounts, every subscription is monthly. Missing amount counts as 0.
- Records store ids, not names: `wallet_id` and `fields.to_wallet_id`; the parser's wallet NAME is mapped to an id right after parsing, so renames never break totals.
- Subscription next date (shown in «Дела») = next `day` of the month at 12:00 MSK, recomputed at display time.
- Lists and «Последние операции» sort by `recordWhen` = `happened_utc ?? created_utc`. `depositEnd` = start day (MSK) + `term_months` → «до DD.MM.YYYY».

## Scripts
- `scripts/build-sw.mjs`, `sw-lib.mjs`, `sw.template.js`: service worker generation after `vite build`.
- `scripts/deploy.mjs`: build and push to the `gh-pages` branch (partial fetch of the live site: file list + small files; files > 5 MB that are new go one per push through the temporary branch `deploy-upload`, then the orphan commit). Model shards are never pushed from the laptop (HTTP 408): they must already be on the site byte for byte, else it stops. They get there from the release `model-qwen3-0.6b-q4km-v1` via `.github/workflows/model-to-pages.yml` (`gh workflow run model-to-pages.yml`).
- `scripts/test-tz.mjs`: the time zone test runner.
- `scripts/pages-like-server.mjs`: serves `dist/` gzip-compressed like GitHub Pages (compressed Content-Length, HEAD too) — the real-model e2e against it checks that the model is not downloaded again after a reload (without `cache-fix.ts` it is: verified 2026-10-25).
- `scripts/check-build.mjs` (`pnpm check:build`, run after `pnpm build`): fails if the shipped app files contain `github_pat`/`ghp_`-style tokens or a URL host other than `api.github.com` (and `www.w3.org` XML namespaces), except the exact link prefix `https://github.com/settings/personal-access-tokens/new` (`ALLOWED_URL_PREFIXES`, Settings → «Ключ доступа»). Hosts inside the wllama chunk only (`WLLAMA_HOSTS`: library fallbacks and comments, never contacted).
