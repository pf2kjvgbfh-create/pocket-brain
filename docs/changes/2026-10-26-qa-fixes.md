## A. Parser bugs (phrase → got → expected)
1. Debts: «Маша должна мне 1500» → expense → **debt owed to me** (no wallet change). «взял в долг у Пети 2000» → idea → **I owe Petya 2000, +2000 to last wallet**. «одолжил Пете 3000» → expense → **Petya owes me 3000, −3000 from wallet**. Add a «Долги» block in «Деньги» (кто → сколько, ± direction) — reuse «Чужие деньги» if simpler.
2. «вернул Ивану 2000» → income → **decrease «Чужие деньги: Иван» by 2000 and −2000 from wallet**. «отдал Ивану 5000 его деньги» → idea → same as return.
3. Amounts in words/abbreviations lost (→ idea): «двадцать пять тысяч за аренду», «пять тысяч бензин», «тысяча двести за кроссовки», «1.5 тысячи такси», «3,5 тысячи парковка», «5к такси», «5 тыс обед». A bare amount + noun without a verb = expense.
4. Several amounts: «купил кофе за 300 и круассан за 250», «потратил 300 на кофе, 500 на такси» → only 300 saved → **save one record per amount**, toast lists both.
5. «снял 5000 с золотой» → **transfer Золотая → Наличные**. «кинули на тинькофф 700» → **income**. «положил на серебряную 1000» → **income** (or transfer from Наличные if «с наличных» said).
6. Deposit: «положил 50000 на вклад» changed no wallet. → **transfer from last wallet into the deposit**; remove the confusing duplicate (wallet «Вклад» vs block «Вклады» — keep one); show end date when term is said.
7. Past time: «напомни сегодня в 3 ночи проверить» at 04:30 MSK → past time accepted, title «ночи проверить». → **past hour today → move to tomorrow**; strip «ночи/утра/вечера» from the title and apply them (3 ночи = 03:00, 7 вечера = 19:00).
8. «во вторник в половину пятого» → Thursday 05.11 12:00 → **next Tuesday 16:30** (половина пятого = 4:30, in reminders default pm when 1–7 without «утра/ночи»). «в субботу в 10 утра» → title must be just the task. «28 марта в 3 часа ночи» → 12:00 → **03:00**. «в понедельник утром» → **09:00**; «днём» 13:00; «вечером» 19:00.
9. No hour («через 3 дня», «5 ноября», «завтра») → 12:00 silently → keep 12:00 but toast says «12:00 (время не названо)»; title never contains «напомни/завтра/через 3 дня/в субботу…».
10. «нетфликс 799 каждое 5 число» → day not recognised → **day 5**. A subscription must NOT auto-launch the reminder Shortcut silently; show «Поставить напоминание о платеже» button instead (one tap) — monthly repeat is not supported by the Shortcut.
11. After a manual tap on «Поставить напоминание» the auto-launch still fires ~5 s later → **cancel auto-launch on manual tap** (risk of duplicate reminders). Show a countdown «Ставлю напоминание через 5… — Не надо».
12. Currency: «100 долларов», «20 евро» → saved as ₽ → **keep currency on the record (100 $), exclude from ₽ totals, show «в рублях не считается»**. «89 рублей 50 копеек» → 89,50. «вчера потратил 500» → **date = yesterday**, «вчера» removed from the title.
13. Same phrase within 10 min silently dropped («Уже записано») → second «кофе 300» lost. → **only drop exact repeats of the same `#t=` URL load (reload/back), not a new dictation**; if in doubt save and show «Записал ещё раз — Отменить».
14. «Последние операции» shows 15 of 50, no «ещё» → add «Показать ещё». Hidden wallet still receives records by name → hidden wallets ignored by the parser. After «Удалить токен» the text «токен не подходит или истёк» remains → clear it.
15. Date field in the editor in WebKit was plain text and edits did not apply → use `type="datetime-local"` that works in WebKit, verify in WebKit emulation.

## B. UX (owner: "press, say, done")
1. **Toast shows WHAT was saved**: «Записал: продукты — 1 250 ₽, Наличные»; «Напомню: позвонить врачу — 27.10 09:00 МСК (у тебя 27.10 02:00)»; «Мысль: первые 40 символов…». Not understood → «Не понял — записал в мысли» + «Изменить».
2. Toast 5 s is too short to fix a mistake → add a card «Последняя запись» at the top of «Новое» with «Изменить / Удалить» that stays until the next phrase (not a confirmation — the record is already saved).
3. «Деньги»: move «Последние операции» above «Вклады»/«Подписки»; tapping a row opens the editor.
4. «Дела»: checkbox «сделано» (done items go to a collapsed «Сделано»), past reminders not on top; subscriptions show next payment date.
5. Settings in plain words: «Резервная копия в интернете», «Ключ доступа» with a working step-by-step instruction (link opens GitHub token page with the right scope pre-filled if possible), «Умный помощник (необязательно)». Red line when there is no backup: «Копии нет — записи только на этом телефоне».
6. Placeholder in the input darker (contrast ≥ 4.5:1); explanation texts ≥ 16 px.
7. If the reminder Shortcut is missing, the user sees nothing — add a short hint under the reminder button: «Не открылось? Нужна Команда «Мозг-напомнить» — как сделать» (opens the steps).
