# SETUP.md — что ты делаешь руками для POCKET-BRAIN («Карманный мозг»)

## Как читать
Делай по одному пункту, в том порядке, в котором чат просит. После каждого шага написано, что увидишь.
Не вышло — остановись и напиши в чат, что видишь на экране. Токен GitHub вставляй ТОЛЬКО в «Настройки» приложения — никогда не в чат.
Всё, что я не мог проверить без твоего телефона, помечено «проверить на телефоне». Названия кнопок в Командах и на GitHub — по памяти авторов инструкций: если на экране называется чуть иначе, ищи по смыслу и напиши мне, как называется на самом деле.

Ссылка приложения: `https://pf2kjvgbfh-create.github.io/pocket-brain/` (чат проверит логин GitHub и исправит эту строку, если он другой).

## 0. Тест телефона (после этапа 0, 3 минуты)
Нужен, чтобы выбрать, какую модель класть в приложение и класть ли вообще.
1. На iPhone в Safari открой `https://pf2kjvgbfh-create.github.io/pocket-brain/test/`. Увидишь: страница с кнопками «Шаг 1» … «Шаг 5».
2. Нажимай кнопки по порядку, после каждой жди ответа. Увидишь: внизу таблица «шаг — число — ок/упало».
3. Если страница перезагрузилась или Safari закрыл вкладку — это тоже результат. Открой страницу снова: она запомнила, до какого шага дошла.
4. Сделай скриншот таблицы и пришли в чат (в ней нет ничего секретного).

## 1. Ключ доступа для копии (токен GitHub, один раз)
Ключ доступа (на GitHub он называется «токен») разрешает приложению писать в твой приватный репозиторий с копией данных, и больше никуда. Пока ключа нет, в «Настройках» красная строка «Копии нет — записи только на этом телефоне».
1. Открой приложение → «Настройки» → блок «Ключ доступа» → «Открыть страницу GitHub». Войди в GitHub. Название `pocket-brain` и срок 1 год уже заполнены (запиши дату в Напоминания — через год ключ надо заменить).
2. «Repository access» → «Only select repositories» → выбери только `pocket-brain-data`.
3. Проверь, что у «Contents» стоит «Read and write» (ссылка выбирает это сама). Больше ничего не включай.
4. «Generate token» → скопируй ключ (он показывается один раз).
5. Вернись в приложение → «Настройки» → поле «Ключ доступа (токен GitHub)» → вставь → «Сохранить». Увидишь: «Ключ сохранён», красная строка пропала, через несколько секунд — «Последняя копия: <время по Москве>».
6. Ключ не вставляй в чат и не сохраняй в заметки. Если случайно вставил — на GitHub удали этот токен («Delete») и сделай новый по этим шагам.

## 2. Команда «Мозг» (после этапа 2)
Быстро (одно нажатие): открой в Safari на iPhone https://pf2kjvgbfh-create.github.io/pocket-brain/install/ (или в приложении «Настройки» → «Установка команд») → «1. Добавить команду «Мозг»». Откроются «Команды» → «Добавить команду». Если Safari сначала спросит про загрузку — «Загрузить», потом открой файл из загрузок (значок со стрелкой вверху). Проверить на телефоне: открывается ли файл на iOS 26.
Если не вышло — вручную: открой приложение «Команды» → «+» → назови команду «Мозг». Добавь четыре действия (ищи в поиске действий по словам):
1. «Диктовать текст» (Dictate Text). Язык: русский. Остановка: после паузы. Проверить на телефоне: работает ли без интернета и пишет ли числа цифрами или словами.
2. «Закодировать URL» / URL Encode — вход: «Продиктованный текст».
3. «Текст» (Text): набери `https://pf2kjvgbfh-create.github.io/pocket-brain/#t=` и сразу после него вставь переменную «Закодированный URL» (нажми на неё в списке переменных над клавиатурой). Всё в одной строке, без пробелов.
4. «Открыть URL» (Open URLs) — вход: результат предыдущего «Текст».
Проверь: нажми «▶». Скажи «тест раз два». Увидишь: открылся Safari, внизу «Мысль: тест раз два» (или «Не понял — записал в мысли: тест раз два») и кнопки «Отменить», «Изменить»; наверху экрана — «Последняя запись» с тем же текстом. Ничего нажимать не нужно — запись уже сохранена (в «Мысли»).

## 3. Кнопка действия
Настройки iPhone → «Кнопка действия» → листай до «Команда» → «Выбрать команду» → «Мозг». Увидишь: рядом с кнопкой написано «Мозг». Зажми кнопку, скажи фразу — должен открыться Safari и внизу появиться, что записано («Мысль: …», «Напомню: …», «Записал: …»). Проверить на телефоне.

## 4. Команда «Мозг-напомнить» (после этапа 3)
Нужна для кнопки «Поставить напоминание»: приложение само уведомлять не умеет, напоминание ставят «Напоминания».
Быстро: на той же странице «Установка» → «2. Добавить команду «Мозг-напомнить»» → «Добавить команду». Название не меняй. Проверить на телефоне: ставится ли напоминание на нужное время (проверка ниже).
Если не вышло — вручную: «Команды» → «+» → назови «Мозг-напомнить». Действия:
1. Сверху нажми на «Принимать …» и оставь только «Текст». Это то, что присылает приложение.
2. «Получить словарь из входных данных» (Get Dictionary from Input) — вход: «Вход команды».
3. «Получить значение словаря» → ключ `title` → потом ещё одно такое же → ключ `due`.
4. «Получить даты из входных данных» (Get Dates from Input) — вход: значение `due`. Проверить на телефоне: время по МСК (приложение шлёт время со смещением +03:00; если в «Напоминаниях» время сдвинулось — напиши мне, я переключу приложение на запасное поле `due_local`, и ты в этом действии выберешь значение `due_local` вместо `due`).
5. «Добавить новое напоминание» — название: значение `title`, дата: результат шага 4.
Проверь: в приложении создай запись «напомни завтра в 19:00 тест» → «Поставить напоминание» (если спросит «Открыть в Командах?» — «Открыть»). Увидишь: в «Напоминаниях» дело «тест» на завтра 19:00 по Москве. Сверь с МСК.
Повторяющиеся платежи в этой версии вручную не автоматизируются: приложение ставит ближайшую дату. Проверить на телефоне, нужен ли тебе повтор — скажи, добавим позже.

## 5. Как пользоваться (важно)
1. Основной путь: кнопка действия открывает приложение ссылкой в Safari.
2. Иконку на Домашний экран ставь только так, как написано ниже.
3. Данные во вкладке Safari iPhone может стереть, если долго не открывать (около недели) — поэтому нужна копия на GitHub (пункт 1). Раз в пару недель смотри в «Настройки»: «последняя копия» свежая?

### Иконка на Домашнем экране
1. Открой приложение в Safari по ссылке `https://pf2kjvgbfh-create.github.io/pocket-brain/`.
2. Нажми «Поделиться» → «На экран Домой».
3. Если есть переключатель «Открыть как веб-приложение» — выключи его. Иначе у иконки будет своё хранилище, и записи из Safari в ней не видны.
4. Нажми «Добавить». Увидишь: иконка с синим фоном и белой буквой «М».
5. Проверить на телефоне: иконка показывает те же записи, что и голос. Если иконка пустая или записей нет — удали её и сделай запасной вариант ниже.

Запасной вариант: «Команды» → «+» → назови «Открыть Мозг» → одно действие «Открыть URL» со ссылкой `https://pf2kjvgbfh-create.github.io/pocket-brain/` → в настройках команды «Добавить на экран Домой». Она открывает приложение в Safari, так что записи всегда те же.

## 5а. «Умный помощник (необязательно)» (только по Wi-Fi)
Без него всё работает: фразы записываются по правилам. Он помогает с короткими непонятными фразами вроде «репетитор 2000 за урок».
1. Подключись к Wi-Fi. Открой приложение → «Настройки» → блок «Умный помощник (необязательно)» → «Скачать и включить (357 МБ)». Увидишь: «Скачиваю… N%», через несколько минут — «Включён: уточняю непонятные фразы в фоне.»
2. Проверить на телефоне: если Safari перезагрузил страницу и написал «Мозг отключён: телефон не потянул» — значит, памяти не хватило; оставь выключенным, всё и так работает.
3. Если написано «Не скачалось» — интернет пропал; нажми ещё раз на Wi-Fi.
