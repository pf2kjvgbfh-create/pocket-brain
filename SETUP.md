# SETUP.md — что ты делаешь руками для POCKET-BRAIN («Карманный мозг»)

## Как читать
Делай по одному пункту, в том порядке, в котором чат просит. После каждого шага написано, что увидишь.
Не вышло — остановись и напиши в чат, что видишь на экране. Токен GitHub вставляй ТОЛЬКО в «Настройки» приложения — никогда не в чат.
Всё, что я не мог проверить без твоего телефона, помечено «проверить на телефоне». Названия кнопок в Командах и на GitHub — по памяти авторов инструкций: если на экране называется чуть иначе, ищи по смыслу и напиши мне, как называется на самом деле.

Ссылка приложения: `https://pf2kjvgbfh-create.github.io/pocket-brain/` (чат проверит логин GitHub и исправит эту строку, если он другой).

## 0. Тест телефона (после этапа 0, 3 минуты)
Нужен, чтобы выбрать, какую модель класть в приложение и класть ли вообще.
1. На iPhone в Safari открой `https://pf2kjvgbfh-create.github.io/pocket-brain/test/`. Увидишь: страница с кнопками «Шаг 1» … «Шаг 5».
2. Нажимай кнопки по порядку, после каждой жди ответа. Увидишь: внизу таблица «шаг — число — ок/упало».
3. Если страница перезагрузилась или Safari закрыл вкладку — это тоже результат. Открой страницу снова: она запомнила, до какого шага дошла.
4. Сделай скриншот таблицы и пришли в чат (в ней нет ничего секретного).

## 1. Токен GitHub для копии (после этапа 4, один раз)
Токен — это ключ, который разрешает приложению писать в твой приватный репозиторий с копией данных, и больше никуда.
1. На iPhone (или ноутбуке) зайди на github.com под своим аккаунтом. Нажми на свой значок → «Settings».
2. Внизу меню: «Developer settings» → «Personal access tokens» → «Fine-grained tokens» → «Generate new token».
3. Name: `pocket-brain`. Expiration: 1 год (запиши дату в Напоминания — потом токен надо заменить).
4. «Repository access» → «Only select repositories» → выбери только `pocket-brain-data`.
5. «Permissions» → «Repository permissions» → «Contents» → «Read and write». Больше ничего не включай.
6. «Generate token» → скопируй значение (оно показывается один раз).
7. Открой приложение → «Настройки» → поле «Токен GitHub» → вставь → «Сохранить». Увидишь через несколько секунд: «последняя копия: <время по Москве>».
8. Токен не вставляй в чат и не сохраняй в заметки. Если случайно вставил — на GitHub удали этот токен («Delete») и сделай новый по этим шагам.

## 2. Команда «Мозг» (после этапа 2)
Открой приложение «Команды» → «+» → назови команду «Мозг». Добавь четыре действия (ищи в поиске действий по словам):
1. «Диктовать текст» (Dictate Text). Язык: русский. Остановка: после паузы. Проверить на телефоне: работает ли без интернета и пишет ли числа цифрами или словами.
2. «Закодировать URL» / URL Encode — вход: «Продиктованный текст».
3. «Текст» (Text): набери `https://pf2kjvgbfh-create.github.io/pocket-brain/#t=` и сразу после него вставь переменную «Закодированный URL» (нажми на неё в списке переменных над клавиатурой). Всё в одной строке, без пробелов.
4. «Открыть URL» (Open URLs) — вход: результат предыдущего «Текст».
Проверь: нажми «▶». Скажи «тест раз два». Увидишь: открылся Safari, внизу карточка с этими словами.

## 3. Кнопка действия
Настройки iPhone → «Кнопка действия» → листай до «Команда» → «Выбрать команду» → «Мозг». Увидишь: рядом с кнопкой написано «Мозг». Зажми кнопку, скажи фразу — должен открыться Safari с карточкой. Проверить на телефоне.

## 4. Команда «Мозг-напомнить» (после этапа 3)
Нужна для кнопки «Поставить напоминание»: приложение само уведомлять не умеет, напоминание ставят «Напоминания».
«Команды» → «+» → назови «Мозг-напомнить». Действия:
1. Сверху нажми на «Принимать …» и оставь только «Текст». Это то, что присылает приложение.
2. «Получить словарь из входных данных» (Get Dictionary from Input) — вход: «Вход команды».
3. «Получить значение словаря» → ключ `title` → потом ещё одно такое же → ключ `due`.
4. «Получить даты из входных данных» (Get Dates from Input) — вход: значение `due`. Проверить на телефоне: время по МСК (приложение шлёт время со смещением +03:00; если в «Напоминаниях» время сдвинулось — напиши мне, я переключу приложение на запасное поле `due_local`, и ты в этом действии выберешь значение `due_local` вместо `due`).
5. «Добавить новое напоминание» — название: значение `title`, дата: результат шага 4.
Проверь: в приложении создай запись «напомни завтра в 19:00 тест» → «Поставить напоминание» (если спросит «Открыть в Командах?» — «Открыть»). Увидишь: в «Напоминаниях» дело «тест» на завтра 19:00 по Москве. Сверь с МСК.
Повторяющиеся платежи в этой версии вручную не автоматизируются: приложение ставит ближайшую дату. Проверить на телефоне, нужен ли тебе повтор — скажи, добавим позже.

## 5. Как пользоваться (важно)
1. Открывай приложение ТОЛЬКО ссылкой в Safari (её открывает кнопка действия).
2. НЕ добавляй её «На экран Домой»: там хранилище отдельное, и приложение будет пустым — твои записи там не видны.
3. Данные во вкладке Safari iPhone может стереть, если долго не открывать (около недели) — поэтому нужна копия на GitHub (пункт 1). Раз в пару недель смотри в «Настройки»: «последняя копия» свежая?
