# ACCEPTANCE.md — приёмка POCKET-BRAIN

Формат строки: `[ ] <что видно>` → после проверки `[x] 2026-10-ДД playwright-webkit+chromium-375px / вручную / iPhone`.
Адрес для всех проверок — живая ссылка `https://<логин>.github.io/pocket-brain/` (не localhost).

**Правило NO CONFIRMATION CARDS (слова владельца).** Фраза из ссылки или из поля сохраняется сразу, без карточки подтверждения и без кнопки «Сохранить». Внизу появляется строка «Записал: …» с кнопками «Отменить» и «Изменить» на 5 секунд. Любая проверка ниже, где раньше была карточка, теперь смотрит на эту строку.

## Часть 1 — ноутбук (проходит чат сам, со скриншотами `scale: 0.5`, WebKit и Chromium, 375 px и 1280 px)
- [ ] Ссылка открывается; первый экран понятен: поле ввода и вкладки «Новое», «Дела», «Деньги», «Мысли», «Настройки»; нет горизонтальной прокрутки на 375 px.
- [ ] Офлайн: открыть один раз, выключить сеть (`setOffline`), перезагрузить — страница открывается и сохраняет запись.
- [ ] `/#t=напомни завтра в 19:00 позвонить маме` → без нажатий внизу «Записал: напоминание, завтра 19:00 МСК» с кнопками «Отменить» и «Изменить»; карточки нет; адрес больше не содержит `#t=`; после перезагрузки записей одна; та же ссылка ещё раз → «Уже записано: …» только с «Изменить», новой записи нет.
- [ ] Расход: «купил воду за пятьсот рублей золотая карта» → без нажатий «Записал: расход 500,00 ₽, Золотая карта»; итог кошелька уменьшился на 500 ₽.
- [ ] Чужие деньги: фраза с именем, суммой и процентом → тип «чужие деньги», итог «чужих денег» вырос.
- [ ] Вклад, подписка («17-го каждого месяца 300 рублей»), идея с тегом → правильные типы и списки.
- [ ] Неуверенный разбор («что-то непонятное про вторник») → сразу «Записал: мысль», текст не потерян, лежит в «Мысли».
- [ ] «Отменить» в течение 5 секунд: записи нет, текст вернулся в поле, написано «Отменено», Команда сама не открылась. «Изменить» открывает правку записи.
- [ ] Кошелёк не назван в фразе → берётся тот, что был в прошлый раз; самый первый раз — «Наличные».
- [ ] Память исправлений: поправил тип и кошелёк у «кофе 300» → следующее «кофе 250» записывается так же (расход, тот кошелёк); после перезагрузки это помнится.
- [ ] Набранный текст: Enter записывает, Shift+Enter переносит строку; кнопка «Записать» делает то же.
- [ ] Напоминание открывает Команду «Мозг-напомнить» само через 5 секунд (если не нажал «Отменить»/«Изменить» и не продиктовал новое); с `#t=` из утерянного черновика после перезагрузки само не открывается.
- [ ] Кошельки: добавить, переименовать, скрыть; скрытый не в списке выбора, но его записи в итогах остаются.
- [ ] Время: везде МСК крупно, местное мелко; тест с `TZ=UTC` и `TZ=America/New_York` — «завтра 19:00» = 16:00Z.
- [ ] «Поставить напоминание» (и автооткрытие) ведёт на адрес `shortcuts://run-shortcut?name=…` с JSON (`title` с хвостом « — 19:00 МСК», `due` с `+03:00`, `due_local`, `due_msk`); кириллица и кавычки раскодируются обратно без потерь; осенний/зимний перевод часов в тесте не сдвигает МСК.
- [ ] Копия (на локальном имитаторе API GitHub): успех → «последняя копия: <время МСК>»; 409 и 422 → повтор со свежим sha; два быстрых сохранения → не больше одного запроса одновременно; файл >1 МБ делится по месяцам и восстанавливается обратно; 401 → «токен не подходит или истёк», сохранение не блокируется.
- [ ] Токена нет ни в выгруженной копии, ни в «Экспорт в Файлы», ни в логах консоли (тест с поддельным токеном); `security-reviewer` без замечаний.
- [ ] Модель (Chromium): куски модели лежат на Pages (каждый < 100 МБ) и грузятся; таблица оценки двух кандидатов на 50 фразах — в `docs/model-eval.md`; выбран победитель.
- [ ] Модель выключена или недоступна → всё работает; пока модель занята, сохранение < 1 с; убитая посреди загрузки страница при следующем открытии отключает модель с понятным сообщением.
- [ ] Эталонные 50 фраз проходят 100% (`pnpm test` зелёный).
- [ ] В публичном репо нет данных: `git ls-files` не содержит копий/экспортов/реальных имён и сумм; в приватном репо данные есть, он приватный (`gh repo view`).
- [ ] В собранной странице нет токенов и внешних адресов, кроме `api.github.com` (проверка `grep` по сборке).

## Часть 2 — с телефона (владелец повторяет сам, ≤ 8 шагов; сначала SETUP, пункты 1–5)
1. На iPhone нажми кнопку действия, продиктуй: «Напомни завтра в девятнадцать ноль-ноль позвонить маме». Увидишь: открылся Safari, внизу сразу «Записал: напоминание, завтра 19:00 МСК» и кнопки «Отменить», «Изменить». Ничего нажимать не нужно.
2. Подожди 5 секунд, не нажимая. Увидишь: запись лежит в «Дела»; адрес в строке Safari без `#t=`. Обнови страницу — запись одна. Проверить на телефоне: откроет ли Safari Команду без нажатия (если iPhone спросит «Открыть в Командах?» — «Открыть»; если Команда не открылась сама — в «Дела» у записи есть кнопка «Поставить напоминание», нажми её).
3. Увидишь: в «Напоминаниях» новое дело на завтра 19:00 по Москве, в названии есть « — 19:00 МСК». Сверь время: проверить на телефоне: время по МСК. Не то время — напиши мне, что показало.
4. Продиктуй: «Купил воду за пятьсот рублей золотая карта». Увидишь: «Записал: расход 500,00 ₽, Золотая карта», без нажатий; в «Деньги» итог уменьшился. Нажми «Отменить» до того, как строка исчезнет, — запись пропадёт, текст вернётся в поле.
5. Включи авиарежим, открой ссылку ещё раз. Увидишь: страница открывается, запись сохраняется сама (диктовка без интернета может не работать — это отдельная проверка: проверить на телефоне).
6. Выключи авиарежим, вставь токен (SETUP, пункт 1) в «Настройки». Увидишь: «последняя копия: <время МСК>» через несколько секунд.
7. Открой приватный репозиторий `pocket-brain-data` на github.com. Увидишь: файл `data/pocket-brain.json` с твоими записями (токена там нет).
8. «Настройки» → «Экспорт в Файлы». Увидишь: файл сохранился в «Файлы». Если что-то из 1–9 не так — одной фразой: «делал X, ожидал Y, увидел Z».
9. Нажми на иконку приложения на Домашнем экране (SETUP, пункт 5). Увидишь: те же записи, что и после голоса. Проверить на телефоне: иконка показывает те же записи, что и голос.

## Не проверено (исполнитель пишет честно; ожидаемо — не меньше этого)
- Память и скорость модели на iPhone (только тест-страница и шаг 5 этапа).
- Диктовка по-русски без интернета; формат чисел в диктовке (цифры или слова).
- Реальный запуск Команды «Мозг-напомнить» и учёт `+03:00` в «Напоминаниях».
- Откроет ли Safari Команду «Мозг-напомнить» сам, без нажатия (через 5 секунд после записи); не заблокирует ли iPhone такой автозапуск.
- Иконка «На экран Домой» без режима веб-приложения: общие ли у неё записи с Safari.
- Реальная отправка на GitHub с токеном владельца и «Восстановить» на настоящей копии.
- Очистка данных вкладки Safari при долгом неиспользовании (~7 дней; не проверяется, закрывается копией).
