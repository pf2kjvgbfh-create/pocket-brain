Установка

Три шага, один раз. Открой эту страницу в Safari на iPhone.

1. Добавить команду «Мозг»

Откроются «Команды» — нажми «Добавить команду». Если Safari сначала спросит про загрузку — нажми «Загрузить», потом открой файл из загрузок (значок со стрелкой вверху).

2. Добавить команду «Мозг-напомнить»

Так же — «Добавить команду». Приложение зовёт её по имени: в «Командах» она должна называться ровно «Мозг-напомнить». Если там стоит другое название (например, с цифрой 1) — переименуй.

3. Повесить на кнопку действия
  1. Открой «Настройки» iPhone → «Кнопка действия».
  2. Листай картинки вбок до «Команда».
  3. Нажми «Выбрать команду» → «Мозг».
  4. Зажми кнопку сбоку и скажи фразу — откроется приложение и внизу будет «Записал: …».
