Установка

Три шага, один раз (четвёртый и пятый — по желанию). Открой эту страницу в Safari на iPhone.

1. Добавить команду «Мозг»

Откроются «Команды» — нажми «Добавить команду». Если Safari сначала спросит про загрузку — нажми «Загрузить», потом открой файл из загрузок (значок со стрелкой вверху). Если старая «Мозг» уже есть — удали её и добавь эту: новая слушает, пока не нажмёшь на экран, и хранит каждую фразу в «Файлах» (папка «Мозг»), так что ничего не теряется.

2. Добавить команду «Мозг-напомнить»

Так же — «Добавить команду». Приложение зовёт её по имени: в «Командах» она должна называться ровно «Мозг-напомнить». Если там стоит другое название (например, с цифрой 1) — удали старую «Мозг-напомнить» и переименуй новую. Новая ставит сразу напоминания на год: платежи, зарплату, итоги недели.

3. Повесить на кнопку действия
  1. Открой «Настройки» iPhone → «Кнопка действия».
  2. Листай картинки вбок до «Команда».
  3. Нажми «Выбрать команду» → «Мозг».
  4. Нажми кнопку сбоку, скажи фразу и нажми на экран — откроется приложение и внизу будет «Записал: …».
4. Умный помощник (по желанию): «Мозг-ИИ»

Разбирает длинный рассказ о деньгах и советует, можно ли купить. Сначала поставь PocketPal и скачай в нём модель — шаги в приложении: «Настройки» → «Умный помощник» → «Как подключить». Потом — «Добавить команду».

5. Голос (по желанию): «Мозг-сказать»

Телефон скажет вслух, когда лимит на еду превышен. Так же — «Добавить команду».
