# HANDOFF.md — как запустить сборку «Карманного мозга»

## Что ты получишь
Веб-приложение по ссылке в Safari: зажал кнопку действия → сказал фразу → внизу карточка «Понял так: …» → «Сохранить». Напоминания уходят в «Напоминания» по Москве, деньги считаются по кошелькам (наличные, вклады, золотая и серебряная карты, Тинькофф — список твой), чужие деньги, вклады, подписки, мысли с тегами. Работает без интернета, копия данных сама уходит в твой приватный репозиторий GitHub. Маленькая модель в странице уточняет карточку фоном и никогда не мешает сохранить.

## Запуск (один раз)
Архитектор уже скопировал пакет в папку `POCKET-BRAIN` на рабочем столе и запустил чат сборки — тебе ничего делать не надо. Пункты ниже — только если придётся запускать заново.
1. Скопируй пакет в папку проекта — вставь в PowerShell одной командой:
   `New-Item -ItemType Directory -Force C:\Users\Lenovo\Desktop\POCKET-BRAIN; Copy-Item C:\Users\Lenovo\Desktop\ArchiTechk\cases\POCKET-BRAIN\pack\* C:\Users\Lenovo\Desktop\POCKET-BRAIN\`
   Увидишь: в папке `POCKET-BRAIN` на рабочем столе 7 файлов `.md`.
2. Открой Claude Code в этой папке, модель **Sonnet** (этап 0). Режим разрешений обычный. Коннекторы: нужны только context7 и браузерный Playwright; остальные выключи (или напиши чату: «выключи лишние коннекторы»).
3. Открой `GENESIS-PROMPT.md`, скопируй весь текст и вставь первым сообщением. `gh` на ноутбуке уже залогинен — чат сам создаст оба репозитория и включит Pages.
4. Чат проходит все этапы подряд сам. Если напишет «Сделай /clear и напиши «продолжай POCKET-BRAIN»» — делай так, всё записано в `STATUS.md`. Быстрый вопрос посреди работы — через `/btw`.
5. Когда чат просит ручной шаг — делай по `SETUP.md`, по одному. Токен — только в приложение, не в чат.

## Что ты проверяешь и когда
- После этапа 0: тест на телефоне (SETUP, пункт 0, 3 минуты) — скриншот в чат. От него зависит модель.
- После этапа 2: собери Команду «Мозг» и кнопку действия (SETUP, пункты 2–3), продиктуй пару фраз — по желанию.
- После этапа 3: Команда «Мозг-напомнить» (пункт 4) — сверь время напоминания с Москвой.
- После этапа 4: токен (пункт 1) — это единственное место, где проверяется настоящая копия на GitHub.
- После этапа 6: блок «С телефона» из `ACCEPTANCE.md`, 8 шагов.

## Честные ограничения
- Данные во вкладке Safari iPhone может стереть, если приложение не открывать около недели. Главная защита — копия на GitHub и кнопка «Восстановить»; раз в пару недель смотри «последняя копия» в Настройках.
- Открывай приложение только ссылкой в Safari. «На экран Домой» даст пустое приложение (хранилища раздельные).
- Эмулятора iPhone на Windows нет: чат проверит всё в WebKit и Chromium на ноутбуке, но скорость и память модели, диктовку без интернета и запуск Команд проверишь только ты на телефоне.
- Команды нельзя прислать файлом — ты собираешь две сам, по шагам (по 4–5 действий).
- iPhone может спросить «Открыть в Командах?» при напоминании — одно нажатие.
- Репозиторий с кодом и моделью — публичный (иначе бесплатные Pages не работают). Данных в нём нет; они только в приватном `pocket-brain-data`.
- Модель может оказаться слишком тяжёлой для телефона — тогда приложение остаётся на правилах, это тоже рабочий результат.

## Если что-то пошло не так
- Чат дважды не может сделать одно и то же — он остановится и напишет «блокер». Принеси его сообщение и `STATUS.md` архитектору.
- Токен вставил в чат — SETUP, пункт 1, шаг 8.
- Приложение пустое после долгого перерыва — «Настройки» → «Восстановить из GitHub».
